# Sakura Team 7 model integration (2026-11-04)

Source: user-uploaded narutoteam7.glb. The 4-person file includes Kakashi, Naruto, Sasuke and Sakura. Sakura has been isolated as an independent mesh without modifying her hand-sign pose. Cropped from the rightmost X segment and centered on the original floor; same 17,185 triangles.

The source contains no color textures, rig, or animation. Approximate pink hair, red costume, skin and dark garments were applied with vertex colors; no existing Naruto or Sasuke model was replaced. The new asset is test-3d/models/sakura-team7.glb. Profile and 5v5 battle both load the same local GLB on the GitHub Pages site; the former remote Sketchfab iframe is no longer invoked. The original Sakura image remains selectable via the Art button.
